1. Resumen teórico

Definición

Una ecuación diferencial ordinaria con variable ausente es una EDO en la que la variable dependiente, la variable independiente, o ambas, no aparecen explícitamente. Esta ausencia permite efectuar un cambio de variable que reduce el orden.

La forma general es:

\[\displaystyle F\bigl(x,y,y',y'',\ldots,y^{(n)}\bigr)=0.\]

Caso I: no aparece la variable dependiente

Si no aparecen \(y,y',\ldots,y^{(k-1)}\), se hace \(v=y^{(k)}\). Para una EDO de segundo orden en la que \(y\) está ausente:

\[\displaystyle v(x)=y'(x),\qquad v'(x)=y''(x).\]
Algoritmo:
  1. Compruebe que la variable dependiente no aparece.
  2. Sustituya \(v=y'\) y \(v'=y''\).
  3. Resuelva la EDO de primer orden para \(v(x)\).
  4. Integre \(y'=v(x)\) para recuperar \(y(x)\).
  5. Aplique las condiciones iniciales, si existen.

Caso II: no aparece la variable independiente

Se considera \(v\) como función de la variable dependiente:

\[\displaystyle v(y)=y',\qquad y''=\frac{dv}{dx}=\frac{dv}{dy}\frac{dy}{dx}=v\frac{dv}{dy}.\]
Algoritmo:
  1. Compruebe que la variable independiente no aparece.
  2. Sustituya \(v(y)=y'\) y \(y''=v\,dv/dy\).
  3. Resuelva la EDO de primer orden para \(v(y)\).
  4. Use \(dy/dx=v(y)\), separe e integre.
  5. Considere por separado \(v=0\) antes de dividir entre \(v\).

Caso III: ambas variables están ausentes

Si la ecuación tiene la forma \(F(y',y'')=0\), se usa \(v=y'\) y \(v'=y''\). Se resuelve la EDO autónoma de primer orden \(F(v,v')=0\) y luego se integra \(y'=v(x)\).

Generalización

Si en una EDO de orden \(n\) no aparecen \(y,y',\ldots,y^{(k-1)}\), se define \(v=y^{(k)}\). La sustitución reduce el orden de \(n\) a \(n-k\); después se integra \(k\) veces para reconstruir \(y\).

2. Ejemplos paso a paso
Seleccione los pasos de la solución

Simbología: use y'' y y', u''(t) y u'(t), o d2u/dt2 y du/dt. Puede usar otras letras, potencias con ^ y productos con o sin *. El resolvedor identifica la variable ausente, reduce el orden y después clasifica la EDO resultante para continuar con los métodos estudiados: variables separables, lineal, Bernoulli, homogénea, exacta o factor integrante cuando corresponda. Las expresiones intermedias se simplifican antes de continuar con el paso siguiente y se consideran por separado las soluciones que puedan perderse al dividir.
